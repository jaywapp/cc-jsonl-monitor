# CC JSONL Monitor 개인정보 처리 안내

적용 버전: 0.4.0

CC JSONL Monitor는 사용자가 선택한 Claude Code JSONL 기록을 같은 컴퓨터의 Chrome 안에서 조회하는 도구입니다.

## 읽는 정보

사용자가 선택한 폴더와 그 하위 폴더·JSONL 파일 또는 선택한 JSONL 파일 하나를 읽습니다. 파일 이름, 크기, 수정 시각, 기록 본문과 그 안의 세션 ID·작업 경로·도구 호출 정보 등을 화면에 표시합니다. 읽기 권한만 사용하고 원본을 수정하거나 삭제하지 않습니다.

## 저장하는 정보

- 최근 연결 최대 8개의 파일 시스템 핸들, 이름, 종류와 마지막 사용 시각을 해당 확장의 IndexedDB에 저장합니다.
- 선택한 화면 테마를 해당 확장의 로컬 저장소에 저장합니다.
- 조회한 기록은 화면과 분석 작업의 메모리에서 처리합니다. 기록 본문을 영구 저장소나 Chrome 동기화 저장소에 복사하지 않습니다.

## 외부 전송

이 버전은 로그, 연결 목록 또는 사용 분석 데이터를 개발자나 외부 서비스로 전송하지 않습니다. 광고, 분석 SDK, 원격 폰트와 원격 실행 코드를 포함하지 않습니다. 확장 페이지의 외부 데이터 연결은 콘텐츠 보안 정책으로 차단합니다.

## 연결 해제와 삭제

최근 연결의 ×를 누르면 저장한 핸들을 제거합니다. 활성 연결이면 화면과 활성 메모리 캐시도 해제합니다. 원본 로그는 그대로 남습니다. Chrome이 보관하는 읽기 권한의 해제는 브라우저에서 별도로 관리할 수 있습니다. 확장을 제거하면 확장의 저장소도 제거됩니다.

## 표시 시 주의점

민감 값 가리기는 알려진 키·토큰 패턴을 화면에서 가리는 보조 기능입니다. 모든 개인정보나 비밀 값을 탐지하는 기능은 아닙니다. 화면 공유나 스크린샷 촬영 전에 표시 내용을 확인하세요.
