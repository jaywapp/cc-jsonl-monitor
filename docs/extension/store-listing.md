## 짧은 설명

Claude Code JSONL 로그를 폴더 트리와 시간순으로 읽는 로컬 전용 뷰어. 폴더 연결, 제목 필터, 다크모드 지원.

## 상세 설명

Claude Code를 사용하며 쌓인 JSONL 기록을 폴더별로 찾고, 요청부터 도구 호출과 결과까지 시간순으로 읽으세요.

CC JSONL Monitor는 사용자가 선택한 로그를 브라우저 안에서 처리하는 읽기 전용 뷰어입니다. 별도 서버 실행이나 계정 가입 없이 폴더 또는 JSONL 파일을 연결해 사용할 수 있습니다.

주요 기능

- 사용자 요청·Claude 응답을 말풍선으로 읽는 대화형 보기와 목록형 전환
- 파일을 바꿔도 현재 탭에서 검색·필터·보기 방식 유지
- 파일 전체의 요청 흐름·도구 사용·반복 호출·오류 뒤 재호출 후보를 근거 기록과 함께 로컬 분석

- 왼쪽 폴더 트리에서 파일을 선택하고 오른쪽에서 기록 조회
- 폴더 연결, 단일 JSONL 파일 열기, 연결 폴더 안의 상대 경로로 이동
- 최근 연결 기억 및 권한 재연결
- 사용자 요청, Claude 응답, 도구 호출, 도구 결과, 생각 기록, 시스템, 진행 상황, 대화 요약, 파일 이력, 세션 정보, 기타 기록별 복수 선택 필터
- 내용 검색, 세션·기간·오류 필터, 시간순 정렬, 내 시간대/UTC 표시
- 기록 내용을 읽기 쉬운 항목으로 표시, 긴 내용 접기, 알려진 민감 값 패턴 가리기
- 파일 변경 안내와 수동 새로고침
- 시스템 설정을 따르는 테마와 밝은 모드·다크모드

시작 방법

1. 확장 아이콘을 눌러 뷰어 탭을 엽니다.
2. 폴더 연결에서 Claude Code 로그가 있는 .claude/projects 폴더를 선택하거나 파일 열기로 JSONL 하나를 선택합니다.
3. 파일 트리에서 기록을 선택하고 검색과 필터를 사용합니다.

데이터 처리

선택한 기록은 브라우저에서만 읽으며 원본을 수정하거나 삭제하지 않습니다. 로그를 개발자 또는 외부 서비스에 전송하지 않으며 광고·사용 분석·원격 실행 코드를 포함하지 않습니다. 최근 연결 정보와 테마 설정은 이 브라우저에 저장됩니다. 민감 값 가리기는 모든 개인정보나 비밀 값을 탐지하는 기능은 아닙니다.

지원 범위

Chrome 데스크톱 122 이상을 대상으로 합니다. 파일당 128 MiB, 한 줄당 512 KiB, 최대 50,000 이벤트를 처리합니다. 검색은 각 이벤트에서 추출한 제목·본문·항목 합계 최대 8,000자와 메타데이터를 대상으로 합니다. 변경 확인은 뷰어 탭이 열린 동안 수행하며, 기록 형식에 따라 일부 내용은 기타 기록으로 표시되며, 확인 가능한 정보만 추출합니다.

이 확장은 독립적으로 개발되었으며 Anthropic 또는 Google의 공식 제품이 아닙니다.

## 단일 목적 설명

사용자가 선택한 Claude Code JSONL 로그 파일을 로컬에서 읽고, 폴더 트리와 세션·시간·기록 제목별 필터를 통해 사용 흐름을 조회하도록 돕습니다.

## 권한 및 데이터 처리 설명

Manifest 권한과 호스트 권한을 추가로 요청하지 않습니다. 사용자가 파일 또는 폴더 선택창에서 지정한 경로에 대해 File System Access API의 읽기 권한을 사용합니다. 파일 쓰기·삭제 권한을 요청하지 않습니다.

로그 본문은 메모리에서 분석하고 표시하며 개발자나 제3자에게 수집·전송하지 않습니다. 최근 연결 핸들, 이름, 종류와 사용 시각은 해당 확장의 IndexedDB에, 테마는 로컬 저장소에 남습니다. Chrome 동기화를 사용하지 않습니다.

데이터 수집 분류 체크박스는 실제 대시보드의 설명을 확인한 뒤 이 동작과 일치하도록 선택합니다. 외부 수집 없음과 기기 내 로그 접근을 혼동해 일괄 답변하지 않습니다. 데이터 판매, 목적과 무관한 사용, 신용도 판단에는 사용하지 않습니다.

## 심사자 테스트 안내

로그인이 필요하지 않습니다. UTF-8 텍스트 파일을 만들고 아래 내용을 넣어 demo.jsonl로 저장하세요. 아래는 가상 데이터입니다.

```jsonl
{"type":"user","sessionId":"store-demo","timestamp":"2026-09-15T00:00:00Z","cwd":"/demo/project","message":{"role":"user","content":"로그인 흐름을 확인해 주세요."}}
{"type":"assistant","sessionId":"store-demo","timestamp":"2026-09-15T00:00:01Z","message":{"content":[{"type":"tool_use","id":"read-demo","name":"Read","input":{"file_path":"/demo/project/auth.ts"}}]}}
{"type":"user","sessionId":"store-demo","timestamp":"2026-09-15T00:00:02Z","message":{"content":[{"type":"tool_result","tool_use_id":"read-demo","content":"가상 도구 결과입니다."}]}}
{"type":"assistant","sessionId":"store-demo","timestamp":"2026-09-15T00:00:03Z","message":{"content":"인증 처리 흐름을 확인했습니다."}}
```

확장 아이콘 → 파일 열기 → demo.jsonl 선택 → 4개 이벤트 확인. 폴더 연결로 demo.jsonl이 들어 있는 폴더를 선택하면 좌측 파일 트리를 확인할 수 있습니다. 필터·설정에서 도구 호출/도구 결과를 선택하고 화면 테마를 변경해 보세요. 작업 패턴을 열면 파일 전체의 도구 사용과 요청 이후 흐름을 볼 수 있습니다. 위 샘플에서는 반복·재시도 후보가 없는 것이 정상입니다.
