# 제품 맥락

## 확인된 요구사항

- Claude Code 사용 중 쌓이는 프로젝트별 JSONL 기록을 쉽게 읽는 전용 뷰어를 제안한다.
- 워크스페이스 루트 경로, 세션, 시간순으로 사용자의 작업 흐름을 파악한다.
- 이번 산출물은 `docs/proposal` 아래 제안서이며 웹 페이지 형식을 선호한다.
- 대상 저장소: https://github.com/jaywapp/cc-jsonl-monitor

- 추가 확인: 사용자가 파일 경로를 직접 지정할 수 있어야 한다. 개별 JSONL 열기를 MVP 필수 기능으로 포함한다.

## Platform

이번 문서는 로컬에서 열 수 있는 웹 문서다. 실제 제품의 배포 플랫폼은 미확정이다.

## 설계 가정 및 제안

- 1차 사용자는 자신의 기록을 복기하는 개발자로 가정한다.
- 실제 뷰어는 로컬 우선, 읽기 전용으로 제안한다. 팀원 추적이나 계정 식별은 범위 밖이다.
- 문서는 별도 설치 없이 읽도록 정적 HTML/CSS/JavaScript로 작성한다.
- 화면 예시는 가상 데이터다. 실제 로그 수집기나 완성된 제품이 아니다.
- 실제 제품의 기술 선택과 성능 수치는 구현 전에 검증할 제안이다.
